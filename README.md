# dataroom/fence — 数据室围栏全文检索库

在内存中保存单个数据室的正文、目录树、用户授权与检索状态，由上层直接
调用。尽调参与者只能检索自己获授权目录（含全部子孙目录）内的文档；
命中统计、相关性得分与排名全部按该用户实际可见的语料计算，隐藏文档
不会产生任何影响。

## 接口

```go
r := fence.NewRoom()
err := r.Load(folders, docs)        // 装载整个房间语料（装载后不可变）
err  = r.ReplaceGrants(uid, fids)   // 整体替换某用户的授权目录集合
total, top := r.Search(uid, query)  // 命中总数 + 得分最高的前 20 条
```

- `Folder{ID, ParentID}`：目录树节点，根节点 `ParentID` 为 0，最多 10 层。
- `Document{ID, FolderID, Text}`：上层已抽取的当前版本正文，ID 唯一。
- `Search` 返回 `[]Hit{DocID, Score}`，按得分降序、同分按文档 ID 升序。
- 授权一个目录即可见其全部子孙；多个授权取并集，重复与祖孙重叠不重复
  计数；空授权看不到任何文档。所有调用需串行执行，库内无锁。

## 检索与计分规则

- 连续英文字母为词，忽略大小写，其余字符均为分隔符；查询含 1–4 个
  不同的词，重复查询词只算一次。
- 只有包含全部查询词的可见文档才算命中。
- 词权重 = 可见文档总数 − 含该词的可见文档数 + 1；文档得分 =
  Σ(词在文档中的出现次数 × 词权重)。统计范围是该用户全部可见文档。

## 实现要点

- 装载期为每篇文档建立排序词表（词 ID + 词频）与全库倒排索引。
- `ReplaceGrants` 用目录可见性位图（子树遍历标记）计算可见文档总数，
  重叠授权在遍历时自然去重。
- `Search` 按代价自适应选择两条路径：可见语料小时枚举可见文档并二分
  查词表；查询词稀有时走倒排表并按位图过滤。两条路径的权重统计都
  覆盖全部可见文档。

## 运行测试

```sh
go test ./...            # 全部正确性与规模负载测试
go test ./... -race      # 竞态检测
go test -run TestLoad -v # 仅规模负载测试（含耗时与内存报告）
```

测试覆盖：祖孙授权重叠后撤去其中一项、两个用户搜索相同词、向不可见
分支加入大量高词频文档（并与无隐藏分支的对照房间逐项比对）、随机
语料与独立参考实现的对拍，以及两类规模负载（20 万文档 / 2 万目录 /
约 2 万词表，各连续 1000 次替换授权并搜索，限时 5 秒，进程内存
不超过 512 MiB）。
